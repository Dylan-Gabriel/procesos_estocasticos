## 📋 Descripción

Repositorio que reúne las implementaciones, tareas y proyectos desarrollados a lo largo del curso de Procesos Estocásticos. Incluye simulaciones de cadenas de Markov, puente browniano, y una plantilla base para métodos numéricos, entre otros.

---

## 🗂️ Estructura del repositorio

```
procesos_estocasticos/
│
├── MARKOV/                    # Simulacion de las cadenas de Markov
├── PROYECTO_PROCESOS/         # Proyecto final de "El movimiento browniano a través de Fourier"
├── Plantilla_metodos-main/    # Plantilla base para métodos numéricos (Streamlit)
├── SIMULACION_DE_RESUMEN/     # Simulaciones y resúmen del video de Yuval Peres
├── puente_browniano/          # Exposición y simulación de "Puente browniano"
├── tareas/                    # Tareas del curso
├── Figure_1.png               # Figura de referencia
└── README.md                  # Este archivo
```

---

## 📁 Contenido

### 🔗 MARKOV
Simulacion sobre las cadenas de Markov, realizada con streamlit y pyhton

### 📂 PROYECTO_PROCESOS
Proyecto final del curso. Incluye la investigacion y desarrollo completo con una simulacion para entender "El movimiento browniano a través de Fourier (La construcción de Wiener, la ley del logaritmo iterado y su relación con Khinchin)"

### 🛠️ Plantilla_metodos-main
Plantilla base en Streamlit para la materia de Métodos Numéricos II. Incluye graficación con Plotly y cálculo simbólico con SymPy. Ver el [README de la plantilla](./Plantilla_metodos-main/README.md) para instrucciones de uso.

### 📊 SIMULACION_DE_RESUMEN
Simulacion y resumen de la conferencia de Yuval Peres.

### 🌉 puente_browniano
Parte la exposición, que el nombre de la carpeta es el tema que se expuso en clase. Incluye las diapositivas (sliders) como una simulación hecha en python con streamlit

### 📝 tareas
Son algunas tareas realizadas en el semestre
